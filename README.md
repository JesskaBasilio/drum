# DRUM
🥁 A Virtual Drum Kit Simulator 
## Descrição curta:

<div>
É uma aplicação web interativa onde o usuário pode tocar diferentes sons de bateria ao clicar nos botões na tela ou ao pressionar teclas específicas no teclado (como "w", "a", "s", "d", "j", "k", "l").

Recursos principais:
<ul>
<li>Interface com botões representando tambores.</li>

<li>Uso de JavaScript para detectar eventos de clique e teclado.</li>

<li>Reprodução de sons correspondentes a cada tecla.</li>

<li>Design simples com foco em interação e som.</li>
</ul>
